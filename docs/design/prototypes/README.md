# Shinrai AI research-workspace prototype

## Start here

[Open the interactive prototype](shinrai-research-workspace-prototype.html) in a browser. It is the visual and interaction source for the approved light research-workspace reset. It runs entirely from fictional local data: no server, credentials, or live market connection are required.

## Interactions covered

- Select a row in the Workspace table to update the prediction detail panel.
- Open a selected prediction to view the full research detail.
- Open Agents to inspect the agent setup modal, choose a template, and save or test a version.
- Run predictions to see the intended inline progress and completed-state behavior.
- Move between Workspace, Experiments, and Arena using the application navigation.
